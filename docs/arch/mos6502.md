# 6502

Part of [Development style](../development-style.md): read General first.

**Pitfalls.** Power-cycle after swapping chips: `R` does not redetect the
part, so the debugger keeps the previous chip's identity and instruction
set; a wrong CPU name after a swap means no power cycle. **[hw]**

`RegsMos6502` takes its `Mems*` as a constructor argument rather than
reaching through `Pins`, because `Pins::_mems` is protected and only
`Target` is a friend. Follow that pattern when a `Regs` needs memory, and
swap the construction order first where `_regs` is built before `_mems`.
