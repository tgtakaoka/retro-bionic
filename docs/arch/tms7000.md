# TMS7000 family

Part of [Development style](../development-style.md): read General first.

**Pitfalls.** Register-file accesses, pushes and pops included, never reach
the bus; `TRAP n` makes two bus cycles, its vector reads.

One table serves the whole family, and the profile
(`tools/cycles_tms7000.py`, recorded on a TMS70C02 as
`tools/tms7000-cycles.jsonl.zst`) takes any family member. **[hw]**

A pending interrupt takes the save's first fetch (see General, Halt
through an entry the CPU takes itself): `park()` runs `JMP $` there until
it has run twice without one, or an entry shows and the save starts at the
handler. The entry is an acknowledge cycle at address 0 and two vector
reads, but a TMS70C02 can be at the vector reads already at the halt, so a
read at FFD0 or above counts too. **[hw]**
